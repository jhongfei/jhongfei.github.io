# jhongfei.github.io

- **[jhongfei.github.io/blindkey](https://jhongfei.github.io/blindkey/)** is the Blind Key sample-blinding app.
  `blindkey/index.html` is a copy of `Index.html` from the private `blind-key` repository. It talks to the
  Blind Key Google Apps Script in the background (`API_URL` in the file).
- `blind-key/` forwards the old address to `/blindkey/`, keeping request links working.
